# 💳 Control de Créditos y Pagos

Aplicación web ligera para llevar el registro y seguimiento de créditos, plazos, abonos y saldos pendientes.

## 🚀 Características
- Registro de créditos con comisión de apertura y cálculo automático de totales.
- Historial de pagos individual por crédito con fecha y notas de referencia.
- Guardado automático en el almacenamiento local del navegador (`localStorage`).
- Interfaz adaptable para dispositivos móviles y computadoras.

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)
